# Quick Start Guide - All Steps\n\n## 📋 Complete Setup from Zero to Production\n\nFollow these steps in order. Each step builds on the previous one.\n\n---\n\n## ✅ STEP 1: Clone Repository\n\n```bash\ngit clone https://github.com/dhanumallina12/Task-Management-Application.git\ncd Task-Management-Application\n```\n\n**Result:** You have the project files on your computer.\n\n---\n\n## ✅ STEP 2: Setup MongoDB Atlas (Database)\n\n1. Go to https://www.mongodb.com/cloud/atlas\n2. Sign up (free account)\n3. Create a new cluster\n4. Go to \"Connect\"\n5. Select \"Connect Your Application\"\n6. Copy connection string\n7. **Keep this string - you'll need it next**\n\n**Result:** You have a cloud database ready.\n\n---\n\n## ✅ STEP 3: Setup Backend\n\n**Terminal 1:**\n\n```bash\ncd backend\nnpm install\ncp .env.example .env\n```\n\n**Edit backend/.env with MongoDB URI**\n\n```bash\nnpm run dev\n```\n\n✅ Backend running on port 5000!\n\n---\n\n## ✅ STEP 4: Setup Frontend\n\n**Terminal 2:**\n\n```bash\ncd frontend\nnpm install\ncp .env.example .env.local\n```\n\n**Edit frontend/.env.local**\n\n```bash\nnpm run dev\n```\n\n✅ Frontend running on port 3000!\n\n---\n\n## ✅ STEP 5: Test Locally\n\n- Visit http://localhost:3000\n- Register account\n- Create tasks\n- Test dashboard\n\n✅ App works locally!\n\n---\n\n## ✅ STEP 6: Push to GitHub\n\n```bash\ngit add .\ngit commit -m \"Production ready\"\ngit push origin main\n```\n\n✅ Code on GitHub!\n\n---\n\n## ✅ STEP 7: Deploy Backend to Render\n\n1. https://render.com\n2. Connect GitHub\n3. Create Web Service\n4. Add environment variables\n5. Deploy\n6. Copy backend URL\n\n✅ Backend deployed!\n\n---\n\n## ✅ STEP 8: Deploy Frontend to Vercel\n\n1. https://vercel.com\n2. Connect GitHub\n3. Import project\n4. Deploy\n\n✅ Frontend deployed!\n\n---\n\n## ✅ STEP 9: Connect them\n\n1. Add backend URL to Vercel env vars\n2. Redeploy frontend\n3. Add frontend URL to Render env vars\n4. Redeploy backend\n\n✅ Connected!\n\n---\n\n## ✅ STEP 10: Test Production\n\n- Visit Vercel URL\n- Create account\n- Create tasks\n- All features work\n\n✅ Live on internet!\n\n---\n\n## 🎉 Done! Your app is live!\n
