# Deployment Guide\n\n## 📋 Prerequisites\n\n- GitHub account\n- Vercel account (for frontend)\n- Render/Railway account (for backend)\n- MongoDB Atlas account (for database)\n\n---\n\n## 🚀 STEP 1: Deploy Frontend to Vercel\n\n### 1.1 Push to GitHub\n```bash\ngit add .\ngit commit -m \"Ready for production\"\ngit push origin main\n```\n\n### 1.2 Create Vercel Account\n1. Go to https://vercel.com\n2. Click \"Sign Up\"\n3. Choose \"Continue with GitHub\"\n4. Authorize Vercel\n\n### 1.3 Deploy Frontend\n1. Click \"New Project\"\n2. Select your repository\n3. Choose \"Next.js\" framework\n4. Click \"Deploy\"\n5. Vercel will auto-deploy\n\n### 1.4 Set Environment Variables\n1. Go to project settings\n2. Click \"Environment Variables\"\n3. Add:\n   ```\n   NEXT_PUBLIC_API_URL=https://your-backend-url/api\n   NEXT_PUBLIC_SOCKET_URL=https://your-backend-url\n   ```\n4. Redeploy\n\n**Frontend is now live!** 🎉\n\n---\n\n## 🚀 STEP 2: Deploy Backend to Render\n\n### 2.1 Create Render Account\n1. Go to https://render.com\n2. Sign up with GitHub\n3. Authorize Render\n\n### 2.2 Create New Web Service\n1. Click \"+ New\"\n2. Select \"Web Service\"\n3. Select your repository\n4. Choose \"Node\" runtime\n5. Set build command: `npm run build`\n6. Set start command: `npm start`\n\n### 2.3 Configure Environment Variables\nAdd these in Render:\n```\nMONGODB_URI=your_mongodb_atlas_uri\nJWT_SECRET=your_jwt_secret\nJWT_REFRESH_SECRET=your_refresh_secret\nPORT=5000\nNODE_ENV=production\nFRONTEND_URL=https://your-vercel-domain.vercel.app\n```\n\n### 2.4 Deploy\n1. Click \"Create Web Service\"\n2. Wait for deployment (5-10 minutes)\n3. Get your backend URL from Render dashboard\n\n**Backend is now live!** 🎉\n\n---\n\n## 🌍 STEP 3: Update Frontend with Production Backend URL\n\n1. Get backend URL from Render (looks like: `https://your-app.onrender.com`)\n2. Go to Vercel project settings\n3. Update environment variables:\n   ```\n   NEXT_PUBLIC_API_URL=https://your-app.onrender.com/api\n   NEXT_PUBLIC_SOCKET_URL=https://your-app.onrender.com\n   ```\n4. Redeploy from Vercel dashboard\n\n---\n\n## 🔐 STEP 4: Setup Custom Domain (Optional)\n\n### Frontend Custom Domain (Vercel)\n1. Go to Vercel Project Settings\n2. Click \"Domains\"\n3. Enter your domain (e.g., app.yourdomain.com)\n4. Update DNS records (instructions provided by Vercel)\n5. Wait for DNS propagation (5-48 hours)\n\n### Backend Custom Domain (Render)\n1. Go to Render service settings\n2. Click \"Custom Domain\"\n3. Enter domain (e.g., api.yourdomain.com)\n4. Update DNS records\n5. Wait for SSL certificate (automatic)\n\n---\n\n## ✅ Verify Deployment\n\n### Test Frontend\n1. Visit your Vercel URL\n2. Should load without errors\n3. Try register → login\n\n### Test Backend API\n```bash\ncurl https://your-backend-url/health\n```\n\nShould return: `{\"status\":\"OK\"}`\n\n### Test API Connection\n1. Login to your app\n2. Create a task\n3. Should save to MongoDB\n\n---\n\n## 🔄 Continuous Deployment\n\nBoth Vercel and Render automatically deploy when you:\n```bash\ngit push origin main\n```\n\n---\n\n## 📊 Monitor Your Apps\n\n### Vercel Analytics\n- Click \"Analytics\" tab\n- View real-time metrics\n- Monitor performance\n\n### Render Logs\n- View application logs\n- Debug errors\n- Monitor resource usage\n\n---\n\n## 🚨 Common Issues\n\n### Backend won't connect to MongoDB\n- Check `MONGODB_URI` is correct\n- Verify whitelist IP in MongoDB Atlas\n- Check credentials\n\n### Frontend shows blank page\n- Check browser console for errors\n- Verify `NEXT_PUBLIC_API_URL` is correct\n- Clear cache and refresh\n\n### CORS errors\n- Update `FRONTEND_URL` in backend `.env`\n- Redeploy backend\n- Clear browser cache\n\n---\n\n## 💡 Tips\n\n1. **Backup your database regularly**\n   - Download from MongoDB Atlas\n\n2. **Monitor logs frequently**\n   - Check Render logs for errors\n\n3. **Test before pushing**\n   - Run `npm run build` locally\n   - Verify all endpoints work\n\n4. **Use git commits effectively**\n   - Good commit messages\n   - Small, focused changes\n\n---\n\n## 🎉 You're Live!\n\nYour Task Management App is now live on the internet!\n\n- **Frontend:** Your Vercel URL\n- **Backend:** Your Render URL\n- **Database:** MongoDB Atlas\n\nShare your app with the world! 🚀\n
