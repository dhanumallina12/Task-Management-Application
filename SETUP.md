# Setup & Deployment Guide\n\n## Complete Instructions from Start to Live\n\n### Prerequisites\n- Node.js 18+\n- Git\n- MongoDB Atlas account\n- GitHub account\n\n---\n\n## LOCAL SETUP\n\n### 1. Clone\n```bash\ngit clone https://github.com/dhanumallina12/Task-Management-Application.git\ncd Task-Management-Application\n```\n\n### 2. MongoDB Setup\n- https://www.mongodb.com/cloud/atlas\n- Create free cluster\n- Get connection string\n- Whitelist IP\n\n### 3. Backend (Terminal 1)\n```bash\ncd backend\nnpm install\ncp .env.example .env\n# Edit .env with MongoDB URI\nnpm run dev\n```\n\n### 4. Frontend (Terminal 2)\n```bash\ncd frontend\nnpm install\ncp .env.example .env.local\nnpm run dev\n```\n\n### 5. Test\n- http://localhost:3000\n- Register & create tasks\n\n---\n\n## PRODUCTION DEPLOYMENT\n\n### 6. Push Code\n```bash\ngit add .\ngit commit -m \"Ready\"\ngit push origin main\n```\n\n### 7. Deploy Backend (Render)\n- https://render.com\n- Web Service → GitHub repo\n- Environment: `npm run build` / `npm start`\n- Add .env variables\n- Deploy\n- Copy URL\n\n### 8. Deploy Frontend (Vercel)\n- https://vercel.com\n- Import project\n- Add env: `NEXT_PUBLIC_API_URL=your-render-url/api`\n- Deploy\n\n### 9. Connect\n- Vercel: Add Render URL to env vars\n- Render: Add Vercel URL to FRONTEND_URL\n- Redeploy both\n\n### 10. Test Production\n- Visit Vercel URL\n- Everything works!\n\n---\n\n✅ **Your app is live!**\n"
